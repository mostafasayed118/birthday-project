# Romantic Microsites

A modern web application for creating beautiful, personalized microsites for special occasions like anniversaries, proposals, birthdays, and Valentine's Day. Built with Next.js, Convex, and Clerk for authentication.

## Project Overview

Romantic Microsites enables users to create, customize, and publish elegant single-page microsites for romantic occasions. Features include:

- Drag-and-drop section management
- Real-time theme customization with presets
- Audio playlists with custom uploads
- Photo galleries, timelines, love notes, and countdown timers
- Authentication via Clerk with secure Convex backend

## Prerequisites

- **Node.js** v18+ (recommended v20+)
- **npm** v9+ or **yarn** v1.22+
- **Git** v2.30+

### Services Required

- **Convex Account** - Backend-as-a-service for database and API
- **Clerk Account** - Authentication provider

## Installation & Setup


Copy the example file and configure your values:

```bash
cp .env.local.example .env.local
```

Edit `.env.local` with your actual credentials (see Configuration section below).

## Configuration

### Required Environment Variables

| Variable | Description | Where to Find |
|----------|-------------|---------------|
| `NEXT_PUBLIC_CONVEX_URL` | Your Convex deployment URL | Convex Dashboard → Project Settings |
| `CONVEX_DEPLOYMENT` | Deployment identifier | Auto-generated by `npx convex dev` |
| `CONVEX_DEPLOY_KEY` | Deployment key for CLI | Convex Dashboard → Settings → Deploy Keys |
| `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` | Clerk publishable key | Clerk Dashboard → API Keys |
| `CLERK_SECRET_KEY` | Clerk secret key | Clerk Dashboard → API Keys |
| `CLERK_DOMAIN` | Your Clerk domain | Clerk Dashboard → Domain |

### Clerk JWT Template Setup

1. Go to Clerk Dashboard → Configure → JWT Templates
2. Create a new template named `convex`
3. Set the audience to your Convex deployment URL (e.g., `https://your-deployment.convex.cloud`)

### `.env.local` Example

```bash
# Convex
NEXT_PUBLIC_CONVEX_URL=https://your-deployment.convex.cloud
CONVEX_DEPLOYMENT=dev:your-deployment
CONVEX_DEPLOY_KEY=dev:your-deployment|your-key

# Clerk
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_your_key
CLERK_SECRET_KEY=sk_test_your_key
CLERK_DOMAIN=https://your-app.clerk.accounts.dev
```

4. Navigate to `/dashboard` to create your first microsite

## Troubleshooting

### "Cannot find module" errors after clone

```bash
rm -rf node_modules package-lock.json
npm install
```

### Convex connection errors

1. Ensure `NEXT_PUBLIC_CONVEX_URL` matches your deployment
2. Run `npx convex dev` to sync configuration
3. Check that your `CLERK_DOMAIN` is correct in both Clerk and `.env.local`

### Authentication not working

- Verify JWT template name is exactly `convex`
- Check that the Clerk domain in `.env.local` matches your Clerk application domain
- Ensure `CLERK_DOMAIN` is set (not `CLERK_FRONTEND_API_URL`)

### TypeScript errors

Run the type check separately:

```bash
npx tsc --noEmit
```

### Port already in use

Change the port for Next.js:

```bash
PORT=3001 npm run dev
```

## Dashboard Guide

### Quick Start

1. Sign in at `/sign-in`
2. Go to `/dashboard/sites`
3. Click "New Site" to create a microsite
4. Select occasion type and customize

### Section Editor

Click the "Edit" button on any section to modify:

| Section | Purpose | Key Settings |
|---------|---------|--------------|
| Hero | Landing banner | Background, title, CTA, Send Love |
| Message | Text block | Font style, alignment, max width |
| Gallery | Photos | Layout (grid/masonry/carousel), columns |
| Timeline | Events | Style (vertical/horizontal), dates |
| Quote | Featured quote | Style (card/inline/banner), background |
| Countdown | Timer | Style, celebration animation |
| Audio | Playlist | Tracks, progress bar, autoplay |
| Map | Location | Coordinates, zoom level |
| Video | Video embed | URL, autoplay, muted |
| Stats | Numbers | Layout, animated counters |
| Memory Highlights | Memory card | Image, heading, text |
| Love Notes | Guest messages | Notes grid |
| Footer | Page end | Social links |

### Theme Customization

Access via the palette icon in the editor:

- **Colors**: Click color swatches to change primary/secondary/background
- **Typography**: Upload custom fonts or use system fonts
- **Spacing**: Adjust section padding, container width
- **Preview**: Use device toggle (mobile/tablet/desktop) to test

### Animation System

Each section has animation settings (clock icon):

1. Enable animations
2. Choose type: Fade, Slide, Scale, Bounce
3. Set duration (Subtle/Smooth/Dramatic presets)
4. Copy settings between sections using the clipboard button

### Quotes Management

Visit `/dashboard/quotes` to:
- Add new quotes with author and tags
- Search existing quotes
- Mark as draft/published
- Feature quotes for homepage display

### Analytics

Visit `/dashboard/analytics` to view:
- Real-time page views and sessions
- Device/browser breakdown
- Geographic visitor distribution
- Hourly visitor trends
